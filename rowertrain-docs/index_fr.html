Paramètres

La page des paramètres vous permet de configurer divers aspects de l'application pour personnaliser votre expérience. Voici les principaux champs de données qu'elle peut contenir :

  • FTP Rameur : exprimé en min/500m.
  • Thème : clair, sombre, système
  • Conserver les fichiers FIT après envoi : si l'option n'est pas cochée et que vous êtes connectés à Strava, les fichiers d'entrainement ne seront pas conservés en local.
  • Masquer la carte et le parcours GPS : si l'option est cochée, la carte et le parcours GPS ne seront pas affichés pendant les sessions d'entraînement ni conservés après.
  • Pause automatique : Si l'option est activée, l'application mettra automatiquement en pause votre session d'entraînement en cas d'inactivité. Vous pouvez ajuster le délai d'inactivité ainsi que le délai de reprise. Si votre rameur fournit des données d'allure trop basses, vous pouvez augmenter le délai d'inactivité pour éviter les pauses indésirables. De même, si vous souhaitez que la session reprenne plus rapidement après une pause, vous pouvez réduire le délai de reprise. Vous pouvez également désactiver complètement la pause automatique si vous préférez gérer manuellement les pauses de votre session d'entraînement.
  • Mode développeur : permet l'activation de certaines fonctionnalités cachées pour le débogage.

La valeur du FTP est utilisée pour calculer les cibles de puissance pour les sessions d'entraînement.

Recherche d'appareils

La page de scan liste les appareils Bluetooth disponibles, comme les machines de fitness et les capteurs. Les appareils suivants sont pris en charge : les rameurs compatibles FTMS et les moniteurs de fréquence cardiaque

Recherche d'appareils

  • Appuyez sur le bouton "Scanner les appareils" pour rechercher les machines de fitness et capteurs Bluetooth à proximité.
  • L'application affichera une liste des appareils découverts, incluant les rameurs et les moniteurs de fréquence cardiaque.
  • Appuyez sur le bouton "Connecter" près de l'appareil pour l'associer à votre téléphone.

Se connecter à Strava

  • Connectez votre compte Strava pour synchroniser vos entraînements.
  • Appuyez sur le bouton de connexion Strava pour authentifier et lier votre compte.
  • Une fois connecté, vos sessions d'entraînement, une fois terminées, peuvent être téléchargées sur Strava.

Démarrage et réalisation d'une session d'entraînement

Démarrage d'une session

  • Assurez-vous que votre rameur et vos capteurs sont connectés.
  • Appuyez sur le bouton "Ouvrir" près du nom de la machine connectée.
  • En haut, vous verrez une liste d'itinéraires prédéfinis, si l'option est activée. Vous pouvez en sélectionner un itinéraire. Si vous ne le faites pas, l' application en choisira un au hasard.
  • Vous pouvez choisir de démarrer une "Course Olympique", "Sortie libre", générer une session d'entraînement ou sélectionner une "Session d'entraînement" sauvegardée

Course Olympique :

  • Sélectionnez la résistance du rameur, si disponible.
  • Appuyez sur "Paris 2024".
  • Une séance d'entraînement en distance libre s'ouvre avec des segments de 250 m.
  • Le meilleur temps personnel est affiché sur la carte et sur le graphique de l'entraînement. Essayez de le battre !

Sortie libre :

  • Sélectionnez "Temps" ou "Distance".
  • Sélectionnez la durée ou la distance souhaitée.
  • Optionnellement, vous pouvez sélectionner des cibles de cadence cible et d'alure.
  • Si la machine prend en charge le réglage de la résistance, vous pouvez sélectionner le niveau de résistance du rameur dans sa plage acceptée. Certaines machines ne prennent pas en charge cette fonctionnalité. Dans ce cas, utiliser les commandes de votre machine pour régler la résistance.
  • Appuyez sur "Démarrer".

Générateur de session d'entraînement :

  • Sélectionnez la durée souhaitée.
  • Sélectionnez le type d'entraînement.
  • Si la machine prend en charge le réglage de la résistance, vous pouvez sélectionner le niveau de résistance du rameur dans sa plage acceptée. Certaines machines ne prennent pas en charge cette fonctionnalité. Dans ce cas, utiliser les commandes de votre machine pour régler la résistance.
  • Appuyez sur "Démarrer".

Session d'entraînement sauvegardée :

  • Sélectionnez une session d'entraînement dans la liste.
  • Appuyez sur "Démarrer la session".

Déroulement d'une session

En haut, vous avez le titre de la session, le métronome et quelques contrôles permettant de couper le son du métronome, le son des alertes, de mettre en pause/démarrer et arrêter la session.

Une fois démarrée, vous verrez en haut une représentation visuelle des intervalles et le temps écoulé actuel et restant ou la distance.

À gauche, vous trouverez l'intervalle actuel avec ses cibles et le temps écoulé et restant ou la distance.

La partie principale est remplie avec les données réelles provenant de la machine de fitness et des capteurs. Les valeurs cibles, telles que définies dans la session d'entraînement, changent de couleur en rouge lorsqu'elles ne sont pas dans la plage souhaitée.

Si votre machine ne fournit pas certaines données, un message indiquant "Aucune donnée" sera affiché dans le champ correspondant.

Si votre machine ne fournit pas les données de résistance et que l'intervalle en cours comporte une cible de résistance, alors la resistance cible exprimée en pourcentage est affichée dans le champ correspondant, permettant de régler manuellement la résistance du rameur.

Si l'option est activée, il y a aussi une carte superposée avec votre position actuelle et l'itinéraire.

Lorsque l'intervalle actuel est sur le point de se terminer, un bip est joué pour vous alerter.

Démarrage d'une session

Commencez à ramer ou pédaler

Si l'intervalle actuel a une cadence cible, alors vous entendrez un son de métronome au rythme de cadence cible. Vous pouvez désactiver ce son en appuyant sur l'icône du métronome. Une représentation visuelle du métronome sera affichée également, permettant de suivre le rythme.

Mise en pause d'une session

Arrêtez de ramer. S'il n'y a pas d'activité, l'application mettra automatiquement la session en pause.

Ou, vous pouvez appuyer sur le bouton pause.

Fin d'une session

Ramez jusqu'à la fin de la session. Vous aurez alors trois options :

  • Sauvegarder la session. Si connecté à Strava, la session est téléchargée automatiquement sur Strava. Vous la trouverez là avec la carte d'itinéraire correspondante. Si pas connecté à Strava, vous trouverez l'activité sous le menu "Activités non synchronisées"
  • Continuer la session : la session sera prolongée pour que vous puissiez continuer à ramer avec les mêmes paramètres que le dernier intervalle.
  • Abandonner la session : toutes les données sont perdues

Vous pouvez appuyer sur le bouton "Arrêter" à tout moment pour terminer la session.

Visualisation et modification des sessions d'entraînement

Appuyez sur le bouton "Sessions d'entraînement".

Il y a des sessions d'entraînement intégrées et des sessions d'entraînement personnalisées. Les sessions intégrées ne peuvent pas être modifiées mais peuvent être dupliquées et modifiées par la suite.

Vous pouvez ajouter, éditer et supprimer des sessions d'entraînement personnalisées. Elles sont stockées localement sur votre appareil mobile.

Lorsque vous créez d'abord une session d'entraînement personnalisée, vous pouvez sélectionner si la session est basée sur le temps ou la distance basée. Une fois sélectionnée et la session sauvegardée, vous ne pouvez pas changer son type.

Vous pouvez ajouter, éditer et supprimer des "intervalles unitaires" et des "intervalles de groupe".

Les intervalles unitaires sont des intervalles avec une durée ou une distance, selon le type de session. Les intervalles de groupe sont des intervalles contenant un ou plusieurs intervalles unitaires avec un nombre de répétitions.

Les intervalles unitaires ont un titre, une durée/distance et des cibles. Vous pouvez choisir d'avoir une cible pour l'allure ou la cadence.

L'allure cible est exprimée en pourcentage et ses valeurs sont calculées en fonction de la valeur FTP que vous avez définie dans les paramètres.

Note sur le niveau de résistance : Vous pouvez définir un niveau de résistance cible de 1 à 15 pour chaque intervalle. Cette valeur sera utilisée uniquement si votre machine de fitness prend en charge le réglage de la résistance via Bluetooth. Certaines machines ont une plage de résistance différente. Dans ce cas, l'application adapte la plage de 1 à 15 à la plage prise en charge par la machine.

Activités non synchronisées

Sélectionnez "Activités non synchronisées" dans le menu burger.

Vous trouverez là les fichiers d'entraînement générés par l'application lorsqu'ils n'ont pas pu être envoyés à Strava.

Pour chacun, vous pouvez essayer de le télécharger sur Strava, le supprimer, ou le partager avec d'autres applications.

Appuyez sur le nom de l'activité. Vous verrez une représentation visuelle des données contenues dans le fichier, comme la vitesse/rythme, la cadence et la fréquence cardiaque

Si vous êtes connecté à Strava et que les téléchargements n'ont pas échoué, la liste devrait être vide.

Mode développeur

Lorsque vous activez le mode développeur dans les paramètres, vous aurez accès aux fonctionnalités prises en charge par la machine de fitness et vous pouvez lire et envoyer des données de et vers la machine.

Avertissement : Utilisez ceci avec prudence !

Depuis la page de scan, sélectionnez la machine et appuyez sur "Ouvrir". Vous verrez deux menus en bas de la page : "Fonctionnalités de données d'appareil" et "Fonctionnalités de machine".

Fonctionnalités de données d'appareil

Voici les données qui peuvent être lues depuis la machine, avec les valeurs actuelles.

Fonctionnalités de machine

Voici les commandes qui peuvent être envoyées à la machine. Parmi elles, vous pourriez pouvoir définir le "niveau de résistance" ou la cible de puissance (mode ERG). Lorsque vous voulez utiliser l'une de celles-ci, envoyez toujours d'abord la commande de contrôle de demande.
